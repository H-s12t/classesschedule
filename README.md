#Class Schedule

A simple course schedule tool for managing and viewing personal class schedules.

## ✨ Features

* 📅 **View Schedule** — View your current weekly class schedule
* ⚙️ **Semester Settings** — Configure semester information
* ➕ **Add Courses** — Add new courses to your schedule
* ✏️ **Edit Courses** — Modify existing course information
* 🗑️ **Delete Courses** — Remove courses from your schedule
* 🔄 **Week Switching** — Switch between different weeks of the semester
* 📖 **Daily Details** — View detailed course information for a specific day
* 💾 **Course Data Storage** — Store basic course and schedule data
* 📝 **Course Notes** — Add notes to individual courses

## 📱 Current Version

**v0.2.0 — Initial Release**

The main features are currently implemented. Some features are still under development and may be improved in future releases.
